# apps/web — UI

Rôle : interface web du harness (React + Vite, port 3080) — **les sessions ICM agentiques**. Le langage visuel est calqué sur DeepSeek Harness (dsh) : tokens repris de `dsh/packages/client/ui-theme` dans `src/styles.css` (palette neutral-bluish, bleu DeepSeek `#4176E6`, boutons primaires noirs, rayons 8/12/16, survols rgba(38,49,72,.06), thème Auto/Clair/Sombre — `prefers-color-scheme` pour Auto, `data-theme` pour les choix explicites), ascenseurs 5px. La **boucle agentique vit dans le navigateur** (`App.tsx` : ICM → modèle via `/api/v1beta` → tool_calls → `/workspaces/:ws/tool` → résultats `role:"tool"` → modèle…, max 12 tours) ; le serveur embarque les API same-origin (plugin Vite, dev et preview) : `/sessions` (journaux — création **avec workspace**, événements, fork, **suppression**) et `/workspaces` (surface ICM agentique — listing, **scaffold**, **ICM assemblée**, aperçu `/file`, **outils** exécutés sous périmètre, **décisions** d'approbation), plus **la passerelle webapi intégrée** (M8 : `src/server/embed.ts` — sauf `W2A_URL` externe, `NYW_WEBAPI_EMBED=0`, port occupé ou Vitest ; le proxy `/api` suit `NYW_WEBAPI_HOST/PORT`).

Entrées : ICM de `packages/core` (prompt système assemblé serveur), journaux de `packages/session`, client v1beta de `packages/adapter-llm`, outils de `packages/tools` (exécutés côté serveur), passerelle de `packages/webapi` (intégrée).
Sorties : application web sur `127.0.0.1:3080` — la vue **Sessions** (dialogue de création titre + workspace, bandeau ICM, chat avec **lignes d'outils dans le flux**, **carte d'approbation** pour write/shell — survit aux rechargements, fork, suppression deux-temps), **menu Paramètres** (thème persisté, diagnostic passerelle vivant, comptes & sessions /u/N + expiration, stats par compte, à propos) ; API `/sessions` + `/workspaces` (scaffold, icm, tool, decision, file) ; passerelle intégrée sur 8081.

Tâches : M1–M6, M8, M9 ✅ (voir MILESTONES.md). **M11** (2026-11-17) : pivot sessions ICM agentiques — vue Workflows retirée, dialogue `NewSessionDialog` (workspace obligatoire, création inline), boucle agentique navigateur avec `AGENT_TOOLS` (`lib/agentTools.ts`, 7 déclarations), `lib/history.ts` reconstruit l'historique modèle depuis les lignes (chat + tours d'outils), `/sessions` gagne DELETE + workspace à la création, `/workspaces` réécrit (scaffold/icm/tool/decision — plus de client LLM serveur), capture README rejouée sur la scène agentique.

**M12** (2026-11-17) : UI/UX agentique professionnelle — sidebar **groupée par workspace** (`Sidebar.tsx` : groupes repliables persistés `nyworkflow.wsCollapse`, « + » par groupe, renommage inline `session-rename-input`) ; `NewSessionDialog` à **trois onglets** (Existant / Créer / **Dossier du disque** — navigateur `folder-picker` avec gardes de séquence : la dernière requête gagne, le chargement initial n'écrase jamais un chemin tapé) ; **onglets Conversation/Activité** par session (`ActivityPanel.tsx` : traces de requêtes `RequestTrace` en mémoire navigateur + lignes d'outils du journal, fusionnées par timestamp) ; **bloc Réflexion** (`ChatView.tsx` `ThinkingBlock` : ouvert pendant le flux, replié d'office à la fin, `appendThinking` dans le store — jamais journalisé ni renvoyé au modèle) ; **modèle groupé + niveau de réflexion** (`ModelPicker` + `lib/modelMeta.ts` : `withThinkLevel` compose `@think=N`, `modelInfo` vient de `GET /api/`) ; boucle M12 dans `App.tsx` : appels **sûrs en parallèle** (`Promise.all`) puis dangereux un à un, **Stop** (`AbortController` + refus de l'approbation en attente), **file d'attente** (un message pendant un tour part à la fin), traces par requête (`appendTrace`/`settleTrace`). Serveur : `workspaces.ts` gagne le **manifeste** `workspaces.json` (dossiers externes, relu par mtime), `GET /workspaces/browse`, `callId` sur tool.call/tool.result (409 uniquement sur dangereux ouvert, `pendingToolCalls`), registre `ShellJobRegistry` pour l'arrière-plan ; `handler.ts` gagne `POST /sessions/:id/rename`. L'hydratation règle un appel sûr orphelin en « interrompu » (pas de fausse carte d'approbation).
