# apps/web — UI

Rôle : interface web du harness (React + Vite, port 3080). Le langage visuel est calqué sur DeepSeek Harness (dsh) : tokens repris de `dsh/packages/client/ui-theme` dans `src/styles.css` (palette neutral-bluish, bleu DeepSeek `#4176E6`, boutons primaires noirs, rayons 8/12/16, survols rgba(38,49,72,.06), thème Auto/Clair/Sombre depuis M8 — `prefers-color-scheme` pour Auto, `data-theme` pour les choix explicites, tokens dupliqués à l'identique dans les deux blocs), ascenseurs 5px. Aucune logique métier ici — tout passe par les packages. Le serveur web embarque aussi trois API same-origin (plugin Vite, dev et preview) : `/sessions` (journaux M3), `/workspaces` (moteur ICM M4 + outils M5 + aperçu de fichiers M6 — exécution des étapes côté serveur, le navigateur ne touche jamais les fichiers directement), et **la passerelle webapi intégrée** (M8 : `src/server/embed.ts` démarre `@nyworkflow/webapi` dans le même processus — sauf `W2A_URL` externe, `NYW_WEBAPI_EMBED=0`, port occupé ou Vitest ; le proxy `/api` suit `NYW_WEBAPI_HOST/PORT`).

Entrées : types et moteur de `packages/core`, journaux de `packages/session`, client de `packages/adapter-llm`, garde de périmètre de `packages/tools` (pour l'aperçu `/file`), passerelle de `packages/webapi` (intégrée).
Sorties : application web servie sur `127.0.0.1:3080` — deux vues : Sessions (chat, fork) et Workflows (étapes, progression, prévisualisation des sorties, exécution, approbation), **menu Paramètres** (M8 : thème persisté `lib/theme.ts`, diagnostic passerelle `lib/gatewayDiag.ts` via `GET /api/`, à propos) ; API `/sessions` et `/workspaces` (runs, advance avec `tools`, approval, file) ; passerelle intégrée sur 8081.

Tâches : M1 ✅, M2 ✅ (sélecteur de modèles, streaming réel), M3 ✅ (sessions), M4 ✅ (API /workspaces), M5 ✅ (endpoint `/approval`, `RunDto.tools`, carte d'approbation + activité d'outils), M6 ✅ (vue workflow complète : onglets, `lib/progress.ts`, `RunDto.outputs`, `GET /workspaces/:name/file`, capture README jouée sur la vue), M8 ✅ (passerelle intégrée au démarrage + menu Paramètres — 2026-11-17) — voir MILESTONES.md.
